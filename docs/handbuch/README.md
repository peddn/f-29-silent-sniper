# Handbuch F-29 Silent Sniper

Das Handbuch beschreibt, wie unser Spiel funktioniert. Es richtet sich an
Spieler, die wissen wollen, warum etwas passiert, und an alle, die das Spiel
abstimmen: Jedes Kapitel endet mit den **Stellschrauben** im Code – Datei,
Name und aktueller Wert –, mit denen sich die Mechanik balancen lässt.

`docs/MECHANICS.md` bleibt die Entwicklerreferenz mit dem Vergleich zum
Original (F-19 Stealth Fighter); das Handbuch beschreibt nur das Spiel, wie es
ist. Ändert sich eine Mechanik, wird ihr Kapitel mitgeändert.
